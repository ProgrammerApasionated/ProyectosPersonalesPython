# 🌧️ Proyecto 04 – Analizador de Lluvias (P4)

### 🌧️ Rainfall Analyzer

Python application that analyzes rainfall and temperature data from multiple locations.  
It calculates statistics and generates a complete weather summary.

---

### 📌 Features

- Load weather data from a file (`lluvias.txt`)
- Calculate:
  - Maximum rainfall and location  
  - Average rainfall  
  - Minimum temperature and location  
  - Average temperature  
  - Ranking of locations by rainfall  
- Generate a complete weather report  
- Interactive console menu with multiple analysis options  

---

### ▶️ How to Run

1. Make sure you have **Python 3.x** installed.  
2. Open a terminal in the project folder.  
3. Run:

```bash
python main.py
```
---
### 🧪 Example Usage
When starting the program, you will see options to:
- Show maximum rainfall
- Show average rainfall
- Show minimum temperature
- Show average temperature
- Show rainfall ranking
- Show full report
- Exit
---
### 📄 Notes
- The file `lluvias.txt` should contain one line per location, formatted as:
    - rain_mm#location#temperature_C
- The program uses object-oriented design with a Precipitaciones class.
- All calculations are modular and reusable.
